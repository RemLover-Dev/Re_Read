## 🌟 معرفی پروژه

**Re:Read** یک ویرایشگر و کتاب‌خوان دسکتاپ مدرن، فوق‌العاده سریع و چشم‌نواز است که با ترکیب **Tauri v2**، **React**، **TypeScript** و زبان قدرتمند **Rust** مهندسی شده است. این نرم‌افزار با هدف رفع معضل همیشگی به هم ریختگی متون راست‌به‌چپ (فارسی و عربی) هنگام ترکیب با کلمات انگلیسی، فرمول‌های ریاضی و کدهای برنامه‌نویسی توسعه یافته است.

همچنین با بهره‌گیری از معماری شیشه‌ای و جلوه‌های بصری شفاف ویندوز ۱۱ و ۱۰ (Acrylic و Mica) و موتور تم پویا شامل **۴۲ شخصیت جهان Re:Zero** به همراه گالری والپیپر، محیطی کاملاً شخصی‌سازی‌شده و بدون حواس‌پرتی را برای مطالعه، یادداشت‌برداری، تحلیل مقالات و حتی استریم و ارائه محتوا فراهم می‌کند.

## ✨ قابلیت‌های برجسته

### 📝 خط پردازش پیشرفته مارک‌داون دوجهته (BiDi)
- **تشخیص هوشمند جهت در سطح پاراگراف**: متن هر پاراگراف به صورت خودکار بررسی شده و پاراگراف‌های فارسی/عربی با جهت راست‌به‌چپ (RTL) و پاراگراف‌های انگلیسی یا کد با جهت چپ‌به‌راست (LTR) نمایش داده می‌شوند.
- **ایزوله‌سازی کلمات درون‌خطی**: عبارات انگلیسی، قطعه‌کدهای داخل متن (`` `code` ``) و ارقام عددی در میان جملات فارسی بدون وارونه شدن ترتیب کلمات یا جابه‌جایی علائم نگارشی (مانند نقطه و پرانتز) نمایش داده می‌شوند.
- **پشتیبانی کامل از استاندارد GFM**: شامل جدول‌ها، لیست کارهای انجام‌شدنی (Task lists)، نقل‌قول‌ها و تیترها.

### 📐 نگارش ریاضی و فرمول‌های LaTeX
- **پشتیبانی با کارایی بالا توسط KaTeX**: نمایش آنی فرمول‌های ریاضی درون‌خطی مانند `$E=mc^2$` و بلوک‌های مجزا مانند `$$\int_{-\infty}^{\infty} e^{-x^2} dx = \sqrt{\pi}$$`.
- **تفکیک جهت ریاضی**: فرمول‌های ریاضی همواره با ساختار استاندارد چپ‌به‌راست نمایش داده می‌شوند و با متن فارسی پیرامون تداخل پیدا نمی‌کنند.

### 📑 نمایشگر یکپارچه اسناد PDF
- **موتور رندرینگ سریع و باکیفیت**: مبتنی بر `pdfjs-dist` برای خواندن روان فایل‌های PDF محلی.
- **امکانات کنترل صفحه**: پیمایش سریع، بزرگ‌نمایی/کوچک‌نمایی، تنظیم عرض متناسب با صفحه و اسکرول پیوسته.

### 🎨 موتور تم پویا با ۴۲ شخصیت Re:Zero
- **۴۲ شخصیت منحصربه‌فرد از ۸ اردوگاه و فرقه**: اردوگاه امیلیا، کروش، آناستازیا، پریسیلا، فلت، جادوگران گناه، فرقه جادوگر و شخصیت‌های تاریخی (از جمله رم، رام، امیلیا، بئاتریس، اکیدنا، سوبارو، راینهارد و ...).
- **پالت‌های رنگی اختصاصی**: هر شخصیت دارای رنگ‌های آکسان، شفافیت پنل، رنگ متن با کنتراست استاندارد WCAG AAA و نور حاشیه مختص به خود است.
- **پایپ‌لاین ۳ لایه والپیپر مقاوم**:
  1. دریافت خودکار تصاویر باکیفیت از طریق APIهای Booru و Zerochan.
  2. کش محلی آفلاین به منظور سرعت بالا و صرفه‌جویی در مصرف اینترنت.
  3. گرادیان‌های رنگی مدرن به عنوان تصویر زمینه جایگزین در صورت عدم دسترسی به شبکه.

### 🪟 ظاهر شیشه‌ای هماهنگ با ویندوز ۱۱ و ۱۰
- **پنجره‌های شفاف Acrylic و Mica**: افکت تاریک/روشن بلور شیشه‌ای از طریق `window-vibrancy` در سمت Rust و متریال بلور در سمت Electron.
- **نوار عنوان (Titlebar) سفارشی**: با قابلیت جابه‌جایی پنجره، دکمه‌های بستن، تمام‌صفحه و کمینه‌سازی، کلید انتخاب حالت مطالعه و انتخابگر تم.

### 🎥 حالت لایه اختصاصی استریمر (Streamer Overlay)
- مناسب برای تولیدکنندگان محتوا و استریمرهای توییچ و یوتیوب جهت نمایش نوتیفیکیشن‌ها، یادداشت‌ها و عنوان ارائه‌ها بر روی تصویر زنده.

### ⚡ معماری دوموتوره قدرتمند
- **Tauri v2 (موتور اصلی و پیش‌فرض)**: مصرف رم باورنکردنی (حدود ۳۰ مگابایت) و عملکرد بومی فوق‌العاده سریع به کمک زبان برنامه‌نویسی Rust.
- **Electron (موتور جایگزین)**: گزینه پشتیبان برای تضمین اجرا روی هر گونه محیط یا سیستمی بدون نیاز به تنظیمات پیچیده.

## 🚀 راهنمای نصب و راه‌اندازی

### پیش‌نیازها

برای اجرای پروژه روی سیستم خود به موارد زیر نیاز دارید:
1. **Node.js** (نسخه ۱۸ یا ۲۰ LTS پیشنهاد می‌شود): [دانلود Node.js](https://nodejs.org/)
2. **Rust و ابزار Cargo** (برای اجرای تائوری): [نصب Rust از طریق rustup](https://rustup.rs/)
3. **C++ Build Tools ویندوز**: ابزارهای ساخت C++ در ویژوال استودیو (Visual Studio Build Tools).

### دانلود و نصب وابستگی‌ها

```bash
git clone https://github.com/your-username/reread.git
cd reread
npm install
```

### تنظیم متغیرهای محیطی

یک کپی از فایل نمونه `.env.example` با نام `.env` ایجاد کنید:

```bash
cp .env.example .env
```

محتوای فایل `.env` (اختیاری):
```env
# حساب کاربری اختیاری در Zerochan جهت دریافت خودکار آرت‌ها
ZEROCHAN_LOGIN=your_username
ZEROCHAN_PASSWORD=your_password

# پورت اجرای وب سرور محلی (به صورت پیش‌فرض 1420)
PORT=1420
```

## 💻 اجرای برنامه

### ۱. اجرای نسخه دسکتاپ با Tauri (پیشنهادی)

اجرای هم‌زمان سرور فرانت‌اند و اپلیکیشن سبک و بومی تائوری:

```bash
npm run desktop:tauri
# یا
npm run tauri:dev
```

### ۲. اجرای نسخه دسکتاپ با Electron (پشتیبان)

```bash
npm run desktop:electron
```

### ۳. اجرای نسخه تحت مرورگر

برای مشاهده و توسعه رابط کاربری به صورت مستقیم در مرورگر:

```bash
npm run dev
```
سپس آدرس [http://127.0.0.1:1420](http://127.0.0.1:1420) را در مرورگر باز کنید.

### ۴. اجرای تست‌های خودکار

جهت اطمینان از سلامت پایپ‌لاین دوجهته، اعتبارسنجی پالت‌ها و رجیستری کاراکترها:

```bash
npm test
```

## 📦 ساخت فایل نصبی و اجرایی ویندوز (`.exe`)

### بیلد در سیستم شخصی

جهت ساخت فایل اجرایی بهینه‌شده به همراه فایل نصبی NSIS:

```bash
npm run tauri:build
```

فایل‌های خروجی در مسیرهای زیر قرار می‌گیرند:
- **فایل اجرایی مستقل (پرتابل)**: `src-tauri/target/release/re-read.exe`
- **فایل نصبی ویندوز (Setup Installer)**: `src-tauri/target/release/bundle/nsis/ReRead_0.1.0_x64-setup.exe`
- **فایل نصبی MSI**: `src-tauri/target/release/bundle/msi/ReRead_0.1.0_x64_en-US.msi`

## 🤖 ساخت خودکار فایل `.exe` با گیت‌هاب اکشنز (GitHub Actions)

در این مخزن یک گردش‌کار کامل و تست‌شده در مسیر `.github/workflows/build.yml` قرار داده شده است که به شما امکان می‌دهد بدون نیاز به کامپایل سنگین روی کامپیوتر خود، خروجی ویندوز را روی سرورهای گیت‌هاب بسازید:

1. **اجرای دستی (Workflow Dispatch)**: در گیت‌هاب به تب **Actions** بروید، ورک‌فلو **Build Windows App (.exe)** را انتخاب کرده و دکمه **Run workflow** را بزنید.
2. **ساخت خودکار با برچسب نسخه (Tag)**: با ارسال یک برچسب مثل `git tag v0.1.0 && git push origin v0.1.0`، گیت‌هاب اکشنز نسخه جدید را کامپایل کرده و به عنوان یک **GitHub Release** منتشر می‌کند.
3. **دانلود خروجی‌ها (Artifacts)**: پس از اتمام اجرا، در پایین صفحه خلاصه اکشن، فایل فشرده `ReRead-Windows-x64` شامل هر دو فایل `.exe` (نسخه پرتابل و نسخه نصبی) آماده دانلود است!

| **حالت مشاهده PDF** | دکمه تغییر حالت نوار عنوان | باز کردن و مطالعه اسناد PDF به همراه ابزارهای جابه‌جایی صفحات و زوم |
| **حالت گالری Booru** | دکمه تغییر حالت نوار عنوان | مرور و تماشای تصاویر هنری کاراکترها و انتخاب والپیپر دلخواه |
| **انتخابگر تم** | آیکون پالت رنگ در نوار عنوان | انتخاب از بین ۴۲ تم شخصیتی جذاب |
| **کنسول توسعه‌دهنده** | `F12` یا `Ctrl + Shift + I` | باز یا بسته کردن ابزارهای توسعه مرورگر |
